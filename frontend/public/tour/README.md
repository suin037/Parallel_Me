# 사용 안내(Tour)에 쓰는 캡쳐본

시뮬레이션 중간부터 결과까지는 **실제로 돌리지 않고 미리 찍어 둔 화면**으로 설명한다.
안내를 한 번 볼 때마다 비교 API 를 부를 이유가 없고(느리다), 결과가 매번 달라지면
안내 영상도 매번 달라지기 때문이다.

이 폴더에 아래 이름 그대로 넣으면 그 단계에 자동으로 붙는다.
**파일이 없으면 그 단계는 조용히 건너뛴다** — 깨진 이미지가 녹화되는 일은 없다.

순서는 실제 결과 화면을 위에서 아래로 내려가는 순서와 같다.

## 시뮬레이션

| 파일 이름            | 무엇을 찍나                                                        |
| -------------------- | ------------------------------------------------------------------ |
| `sim-choices.png`    | 선택지 두 칸을 채운 입력 화면 (분석 영역 · VS · '조건 N개 입력됨'이 보이게) |
| `sim-details.png`    | 그 아래 '일과 관련된 비교' + '더 정교하게 보고 싶다면'(공고·가치관·지금 마음) |

## 결과 — 1단계 (결과 요약)

| 파일 이름                 | 무엇을 찍나                                                   |
| ------------------------- | ------------------------------------------------------------- |
| `result-core.png`         | CORE INSIGHT 두 선택의 핵심 차이 + UNIVERSE A·B 카드          |
| `result-story.png`        | 카드를 눌러 열리는 상세 이야기 모달 (지금 / 변화 과정 / 그 이후) |
| `result-stats.png`        | A/B 기본 비교 통계 + 선택별 모델 참고                          |
| `result-notes.png`        | 숫자를 읽는 배경 (관측 안 된 지표 · 소득 증감 · 명목 경고)      |
| `result-trajectory.png`   | 1·3·5·10년 뒤 관측 변화 (가처분소득 · 직업 만족 · 생활 만족)    |

## 결과 — 2단계 (비교하고 선택)

| 파일 이름                 | 무엇을 찍나                                                   |
| ------------------------- | ------------------------------------------------------------- |
| `result-insights.png`     | 결과에서 더 읽을 수 있는 것 — 격차 · 결과 범위 · 표본 카드 3장  |
| `result-baseline.png`     | 만족도 세부 항목 · 두 집단의 출발점 + 매칭에 반영된 조건        |
| `result-tabs.png`         | 탭 네 개가 보이는 상태의 수치 비교 탭 (지표별 격차 · 참고 기준) |
| `result-record.png`       | 기록 근거 탭 (신호 막대 + 내 기록으로 본 해석)                  |
| `result-decision.png`     | 오른쪽 칸 — 결정 포인트 · 어느 방향을 더 알아볼까요 · 제3의 길   |
| `result-save.png`         | 화면 맨 아래 — 보관함에 저장 / 나가기                           |

## 찍을 때

- 가로로 넓게(1280px 이상) 찍으면 안내 말풍선 위 공간에 크게 들어간다.
- 오른쪽 칸(결정 포인트)은 탭을 바꿔도 그대로라, `result-decision.png` 는 그 칸만 잘라 찍어도 된다.
- `.png` 대신 `.jpg`·`.webp` 를 쓰려면 `src/data/tour.js` 의 `shot:` 경로만 고치면 된다.
- 개인정보가 들어간 화면은 넣지 않는다. 이 파일들은 그대로 배포에 실린다.
