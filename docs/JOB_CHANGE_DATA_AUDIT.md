# 이직 예측 데이터·모델 감사

조사일: 2026-08-09  
범위: 저장소에 보관된 GOMS·YP2021·KLIPS 정제/원본 데이터, 학습 코드, 모델 artifact, `/predict`·`/compare` 출력

## 1. 결론

- 현재 이직 예측의 가장 강한 결과는 **이직이 익년 소득에 미치는 효과**, **장기 소득 관측 궤적**, **재이직/이탈 위험**이다.
- 만족도 데이터는 보유하고 있으나, 현재 비교 화면의 만족도 궤적은 선택 A/B별 인과효과가 아니라 **비슷한 청년 집단의 공통 관측 궤적**에 가깝다.
- 저장소에는 현재 모델이 사용하지 않는 **KLIPS 건강·삶의 만족·스트레스·수면·근무시간·야간/주말근무·출퇴근시간** 데이터가 있다.
- 따라서 `재정 안정도`는 지금도 근거 있게 개선할 수 있지만, `성장 가능성`과 `삶의 질`은 누락 데이터를 이직 전후 패널로 다시 구성하고 검증한 뒤 점수화해야 한다.
- 회사명은 현재 정제 데이터와 모델 입력에 없으며 특정 회사 단위 예측에는 사용할 수 없다.

## 3. 현재 모델이 실제 사용하는 입력

API가 받을 수 있는 공통 입력은 다음과 같다.

- 나이, 성별, 전공, 학점
- 현재 월소득
- 직무 만족도, 삶의 만족도, 행복감
- 정규직 여부, 기업 규모, 학력

하지만 모든 모델이 이 입력을 전부 쓰지는 않는다.

### GOMS KNN

나이·성별·전공·소득·만족도·삶의 만족·행복·정규직·기업 규모를 이용해 유사 사례를 찾는다.

### GOMS 인과모델

이질적 효과 변수는 나이·성별·전공·현재 만족도 중심이다. 결과값은 현재 월소득이며, 이직 여부가 처치 변수다.

### KLIPS 인과모델

현재 임금·근속기간·직종·기업 규모를 통제해 `이직 → 익년 실질임금` 효과를 추정한다. 현재 서비스 입력에 근속기간과 구체적 직종 코드가 없어 일부 값은 학습 중앙값으로 대체될 가능성이 있다.

### KLIPS 생존모델

재직기간과 이직 이벤트로 향후 이탈 위험을 계산한다. 건강·근무환경 변수는 현재 배포 artifact에 연결되지 않았다.

## 4. 현재 출력의 정확한 의미

| 출력 | 현재 의미 | 주의점 |
|---|---|---|
| expected_wage | 유사 집단의 기대 월소득 | 개인의 확정 미래가 아님 |
| causal_effect | 이직이 익년 임금에 미친 조건 보정 효과 | GOMS 보고서 기준 95% CI가 0을 포함함 |
| income trajectory | 비슷한 KLIPS 응답자의 장기 소득 분포 | 기본적으로 관측 궤적 |
| satisfaction | 비슷한 YP 청년의 만족도 궤적 | 현재 A/B 선택별로 분기되지 않음 |
| satisfaction facets | 직무·성장·소득·안정·장래성 만족도 | 선택 효과가 아니라 집단 관측값 |
| regret/risk | 이직 이탈 또는 창업 폐업 누적확률 | 심리적 후회 확률로 해석하면 안 됨 |
| health context | 외부 집단 건강 통계 | 개인별·선택별 예측이 아님 |

현재 `training_report.json`의 GOMS 인과효과는 -16.23만원이고 95% 구간은 -53.64~+21.19만원으로 0을 포함한다. 따라서 이 보고서만으로는 평균적인 소득 상승/하락을 확정할 수 없다. 이 보고서는 GOMS 학습 실행 기록이며, 현재 함께 존재하는 KLIPS artifact의 검증 결과까지 통합한 최신 보고서는 아니다.

## 5. 아직 못 쓰고 있는 핵심 변수

### 바로 검토할 가치가 높은 변수

| 상위 지표 | 후보 변수 | 데이터 | 상태 |
|---|---|---|---|
| 재정 안정도 | 실질임금, 소득 하락 여부, 정규직/종사상지위, 기업 규모, 근속·재이직 | KLIPS/GOMS/YP | 일부만 사용 |
| 성장 가능성 | 자기발전 만족, 장래성 만족, 직무 만족, 직종 변화 | YP/GOMS/KLIPS | 궤적 표시만 일부 사용 |
| 삶의 질 | 삶의 만족, 행복, 건강, 스트레스, 우울, 수면 | KLIPS health/GOMS | 대부분 미연결 |
| 삶의 질 | 실근무시간, 장시간·야간·주말근무, 유연근무, 통근시간 | KLIPS health26a | 미연결 |

KLIPS health의 건강 값은 거의 전 행에 있고, 삶의 만족·행복·웰빙 값은 약 86.1%에 있다. KLIPS health26a의 스트레스·우울·수면은 23,364행에 있으며, 취업자 대상 근무환경 변수는 약 13,000행에 있다.

### 바로 넣으면 안 되는 이유

- `health26a`는 특정 부가조사 시점 자료라 장기 패널 전체에 동일하게 존재하지 않는다.
- 이직 후 측정값을 이직 전 예측 입력으로 쓰면 데이터 누수가 된다.
- 만족도·건강을 결과로 예측하려면 동일 인물의 `t 시점 이직 여부 → t+1 결과` 형태로 다시 만들어야 한다.
- 기존 `klips_module/train_layer4.py`에는 건강 변수를 넣는 실험 코드가 있지만 현재 서비스가 읽는 `lifelines_klips.pkl` 학습 파이프라인과 분리되어 있다.

## 6. 확인된 데이터 품질 문제

- GOMS의 첫 직장 소득은 약 78.7%가 결측이다. 문항 구조상 이직자 중심 응답이라 단순 결측 대체하면 안 된다.
- GOMS 이직/퇴직 이유도 약 70~78%가 결측이며, 주로 해당 경험자에게만 묻는 조건부 문항이다.
- YP 전체에는 비취업자가 포함되어 소득·직업 변수 결측이 약 54~97%다. 취업자 및 유효 전이 표본을 따로 정의해야 한다.
- YP `occupation_raw`는 정제 결과에서 약 92%가 결측이므로 현재 형태로 직종 개인화에 쓰기 어렵다.
- KLIPS 기업 규모는 약 76%가 결측이다. 대체값 사용 시 신뢰도와 missing flag를 함께 반영해야 한다.
- 현재 Python 환경은 NumPy 2.0과 일부 `numexpr`·`bottleneck` 바이너리 호환 경고가 발생한다. 재학습 전에 환경을 고정해야 한다.

## 7. 이직 모델 수정 순서

1. **타깃 재정의**: 이직을 `t→t+1 직장 변경`으로 통일하고 실직·재취업·직무변경을 구분한다.
2. **통합 패널 생성**: KLIPS base와 health를 `pid+wave`로 병합하고, 입력은 t 시점, 결과는 t+1 시점으로 이동한다.
3. **세 결과 데이터셋 생성**:
   - 재정: 익년 실질임금, 소득 감소 여부, 재직 지속
   - 성장: 익년 자기발전/장래성 만족 또는 직종 변화
   - 삶의 질: 익년 삶의 만족·행복·건강; 부가조사는 별도 보조 분석
4. **기준선 모델부터 검증**: 이직/유지 표본 수, 결측, overlap, train/test 개인 분리, 신뢰구간을 확인한다.
5. **모델을 지표별로 검증**: 소득·만족도·건강 결과를 각각 검증하되 API에서는 세 상위 지표로 묶는다.
6. **점수화는 마지막에 수행**: 검증된 원결과만 0~100 요약점수로 변환하고 구성요소·표본·출처를 함께 반환한다.
7. **UI 연결**: 재정 안정도·성장 가능성·삶의 질 카드 → 세부 원자료와 신뢰 수준 바텀시트 순서로 연결한다.

## 8. 당장 권장하는 첫 구현 범위

첫 번째 반복에서는 외부 데이터를 더 추가하지 않고 KLIPS 내부 데이터만 사용한다.

- 재정 안정도: 익년 임금 효과 + 소득 감소 위험 + 재이직 위험
- 성장 가능성: YP 자기발전·장래성 만족도는 우선 관측 근거로 표시하고, A/B 인과점수는 보류
- 삶의 질: KLIPS의 삶의 만족·행복·건강을 이직 전후로 연결해 실제 선택별 차이가 검증될 때까지 점수 대신 변화 방향과 근거 수준을 표시

이 범위를 검증한 후 근무시간·스트레스·수면 부가조사를 삶의 질 보조 모듈로 추가한다.

## 9. 1차 통합 패널 생성 결과

`preprocess/build_klips_job_change_panel.py`로 KLIPS base·health·health26a를 `pid+wave` 기준으로 연결했다. 입력은 t 시점, 이직 여부와 결과는 연속된 t+1 시점으로 제한했다.

- 분석 전이: 39,395건
- 고유 인원: 8,933명
- 이직 전이: 5,819건(14.8%)
- 이직자의 유효 임금쌍: 3,238건
- 삶의 만족·행복 전후쌍: 유지 약 27,400건, 이직 4,719건
- 건강 전후쌍: 유지 33,558건, 이직 5,819건
- 스트레스·수면·근무환경 t+1 값: 4,783건(전체의 12.1%)

단순 기술통계에서 이직 집단의 임금 변화 중앙값은 +19.57만원(+7.53%), 유지 집단은 -0.90만원(-0.39%)이었다. 삶의 만족·행복 평균 변화도 이직 집단이 더 높게 나타났지만, 이는 연령·직종·기존 임금·자기선택을 보정하지 않은 값이므로 인과효과로 해석할 수 없다.

이 결과로 재정과 삶의 질 결과변수는 모델 검증을 시작할 만큼의 표본이 확인됐다. 스트레스·수면·근무환경은 커버리지가 12.1%이므로 주모델이 아니라 별도 보조 분석으로 다루는 것이 적절하다.
