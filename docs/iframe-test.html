iframe 임베드 테스트

전시관 뷰페이지가 우리 사이트를 프레임으로 감쌌을 때를 흉내낸다. 이 파일을 아이폰·아이패드 사파리에서 열어보는 게 핵심 — PC·안드로이드는 원래 되던 환경이라 이 테스트로 구분되지 않는다.

⚠ 주소의 하이픈은 두 개다(parallel--me). parallel-me.vercel.app(하이픈 하나)은 컨셉이 비슷한 다른 서비스이므로 제출 서류에 적을 때 반드시 확인할 것. 관람객은 QR 로 들어오므로 현장에서는 문제되지 않는다.

확인할 것

  1. 랜딩에 체험하기 / 나만의 계정 만들기 두 버튼이 보이는가
  2. 체험하기 → 카드 7장이 뜨는가 (흐린 카드가 있으면 안 됨)
  3. 카드를 누르면 나의 우주로 넘어가고 별·기록이 채워지는가 — 이게 오늘 고친 부분이다. 빈 우주가 뜨면 실패
  4. 뒤로 가서 다른 카드를 누르면 그 사람 기록으로 바뀌는가
  5. 가로 스크롤이 생기거나 잘리는 곳이 없는가 (반응형)

안 되는 게 정상인 것

  • 시뮬레이션 숫자 — 백엔드가 아직 없어 데모값이 뜬다
  • 챗봇·기업분석·N년 뒤 — qmode 서버 미배포
  • 결과 화면 장면 이미지 — Cloudflare 키 미설정

왜 3번이 중요한가

  • 이 앱은 상태를 전부 브라우저 저장소에 넣는다. 크로스 오리진 iframe 안에서는 사파리·iOS가 그걸 막는다 (크롬·파이어폭스는 파티션 저장소로 동작).
  • 막힌 채로 두면 카드를 눌러도 슬롯이 안 써지고 빈 우주가 뜬다 — 에러도 안 나서 원인을 못 찾는다.
  • 그래서 저장소를 safeStorage.js 로 감싸 막히면 메모리로 대신하게 했고, 세션을 날리던 전체 새로고침도 걷어냈다.
  • iOS는 크롬을 써도 엔진이 WebKit이라 사파리와 같다.
