안 떠도 정상인 것

  • Claude 해설이 빠지고 배너만 뜨는 경우 — 하루 한도(2000회)를 넘겼을 때의 의도된 동작이다. 숫자·그래프는 그대로 나온다. 오늘 사용량은 0이라 지금은 안 뜬다.
  • 결과 화면 장면 이미지 — 이미지 생성 키가 아직 안 붙어 있다.
  • 진학(enroll) 선택지의 인과효과 — 학습 표본이 부족해 의도적으로 안 돌린다.

왜 4번이 핵심인가

  • 이 앱은 상태를 전부 브라우저 저장소에 넣는다. 크로스 오리진 iframe 안에서는 사파리·iOS가 그걸 막는다 (크롬·파이어폭스는 파티션 저장소로 그럭저럭 동작).
  • 막힌 채로 두면 카드를 눌러도 슬롯이 안 써지고 빈 우주가 뜬다 — 에러도 안 나서 원인을 못 찾는다.
  • 그래서 저장소를 safeStorage.js 로 감싸 막히면 메모리로 대신하게 했고, 세션을 날리던 전체 새로고침도 걷어냈다.
  • iOS는 크롬을 써도 엔진이 WebKit이라 사파리와 같다. 아이폰 하나면 검증이 끝난다.

폰에서 여는 법

  • 이 파일을 카톡·메일로 자기 폰에 보내 열거나,
  • PC에서 이 폴더에 대고 python -m http.server 8080 을 띄우고 폰으로 http://<PC IP>:8080/iframe-test.html 접속.
  • 둘 다 같은 파일이라 결과는 같다. 카톡 쪽이 빠르다.
