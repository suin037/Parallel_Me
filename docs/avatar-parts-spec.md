# 아바타 파츠 납품 규격 (머리 · 눈)

새로 그린 머리·눈을 이 앱에 꽂기 위한 규격입니다.
**여기 맞춰서 주시면 그대로 들어가고, 어긋나면 재작업이 생깁니다.**
아래 항목은 전부 실제로 한 번씩 깨져서 고친 것들입니다.

원본: ToonHead by Johan Melin, CC BY 4.0.
개작은 허용되지만 **저작자·라이선스·변경 사실 표기는 지우면 안 됩니다.**

## 1. 머리 (hair)

### 1-1. 색

- 머리색으로 칠할 면은 **전부 같은 하나의 색**으로 통일. 기준색 **`#A55728`**
  → 앱이 이 색만 찾아서 사용자가 고른 머리색으로 바꿉니다. 두 가지 색을 쓰면 한쪽만 바뀝니다.
- **음영은 `fill="black" fill-opacity="0.2"`, 테두리 없음**
  → 원작자가 언더컷·귀·코에 쓰는 방식과 동일합니다. 기준색으로 칠하면 음영도 머리색을 따라가 버립니다.
- 음영은 **꼭 필요할 때만**. 빌트인 파츠(뾰족머리·번머리·옆가르마)는 음영이 없습니다.
  넓게 깔면 모자 챙처럼 보입니다 — 실제로 그렇게 나와서 걷어냈습니다.

### 1-2. 선

- **`stroke="black"` 만 쓰고 `stroke-width` 는 넣지 마세요.**
  원본 파츠가 기본값(1)을 쓰기 때문에, 굵기를 지정하면 그 파츠만 테두리가 도드라져 따로 놉니다.
- Figma에서 **`strokeAlign` 을 `CENTER`** 로. `INSIDE` 면 export가 mask + 외곽선으로 풀려
  22KB짜리가 나옵니다 (`CENTER` + flatten 이면 2KB 안팎).

### 1-3. 형태

- **하나의 path 로 flatten** 해서 주세요. 조각을 여러 개 얹으면 경계선이 보입니다.
- **옆머리를 사각형 슬래브로 따로 붙이지 마세요** — 귀마개처럼 보입니다.
  바깥 윤곽을 통으로 만들고 얼굴 구멍을 파내는 쪽이 한 덩어리로 읽힙니다.
- 일자 앞머리를 만들 때 얼굴 구멍의 **윗변은 평평**해야 합니다. 타원으로 파면 뱅이 됩니다.
- 잔결(톱니)은 넣지 마세요. 이 화풍에서는 물방울 무늬처럼 보입니다.

### 1-4. 실루엣 주의

- 볼 높이(y ≈ 400)에서 폭이 넓어지면 **곧바로 여자 단발로 읽힙니다.**
  남자 머리는 폭을 두상(x 194~574)에 묶고 **길이는 아래로만** 주세요.
- 끝을 바깥으로 마는 것(플립)도 같은 이유로 피해주세요.

### 1-5. 같이 알려주실 것

| 항목 | 예 |
|---|---|
| 이름 (한국어) | "남자 리프컷" |
| 귀를 덮는가 | 예 / 아니오 → `HAIR_COVERS_EARS` 등록 여부가 갈립니다 |
| 뒷머리가 필요한가 | 없음 / 목덜미 / 어깨 / 긴 생머리 / 긴 웨이브 |
| 분류 (카메라 인식용) | 덮머 / 가르마 / 짧은머리 / 펌 / 리프컷 / 장발 |

> 귀를 덮는 머리인데 안 알려주시면, 앱이 귀를 머리 위에 다시 그려서 **귀가 머리를 뚫고 나옵니다.**

## 2. 눈 (eyes)

### 2-1. 구조를 지켜주세요

앱이 눈을 **좌 · 우 각각 3조각**으로 가정하고, 이 순서대로 붙어 있어야 합니다:

```
<path d="…" fill="#F6F1E4"/>   ← 흰자
<circle … fill="#4B2422"/>      ← 눈동자
<path d="…" fill="#4B2422"/>   ← 윗눈꺼풀 + 속눈썹
```

왼눈 3조각 → 오른눈 3조각 순서입니다. 이 구조라야 아래가 됩니다:

- **비율·기울기 조절** — 흰자·눈꺼풀만 늘이고 눈동자는 둥근 채로 유지 후 흰자로 잘라냄
  (같이 누르면 동공이 타원이 되어 고양이 눈처럼 보입니다)
- **속눈썹 on/off** — 눈꺼풀 path 는 남기고 속눈썹만 제거

### 2-2. 속눈썹

속눈썹은 **윗눈꺼풀 path 끝의 꼬리**로 그려주세요 (지금 원본과 같은 방식).
따로 떼어 별도 path 로 주시면 더 좋습니다 — 그러면 제거가 확실해집니다.

> 속눈썹 path 를 통째로 지우면 눈꺼풀 선까지 사라져 눈이 허옇게 뜹니다.
> 지금은 꼬리 좌표만 잘라내고 있는데, 새 눈은 좌표가 달라 그 정규식이 안 먹습니다.

### 2-3. 같이 알려주실 것

눈 종류마다:

| 항목 | 예 |
|---|---|
| 이름 | "무쌍 (가늘고 긴)" |
| 왼눈 흰자 path 의 시작 좌표 | `M321.5 373.47` |
| 오른눈 흰자 path 의 시작 좌표 | `M445.56 373.47` |
| 좌 · 우 눈동자 중심 | (314, 413.5) / (453, 413.5) |

이 좌표를 앵커로 등록해야 눈 크기·간격 조절이 동작합니다.

### 2-4. 참고

눈을 6~8종 **다 그리실 필요는 없을 수도** 있습니다.
기본형 2~3종만 주시면, 가로·세로 비율과 기울기를 파라미터로 돌려
무쌍 / 아몬드 / 올라간 눈 / 처진 눈 정도는 코드에서 파생시킬 수 있습니다.
그림을 새로 그리는 것보다 화풍이 안 깨집니다.

## 3. 납품 형태

- SVG 파일 (파츠당 1개) 또는 `<path>` 문자열
- `<svg>` 래퍼는 있어도 없어도 됩니다. 안쪽 내용만 씁니다
- 파일명은 영문 id 로 (`men-leaf.svg`, `eye-mono.svg`)
- 위 "같이 알려주실 것" 표를 **한 장으로 정리해서 같이** 주세요

## 4. 받은 뒤 제가 하는 일

1. `frontend/src/data/customParts.js` 에 파츠 등록
2. `frontend/src/data/avatarOptions.js` 의 `HAIR_STYLES` / `EYES` 에 추가
3. 귀를 덮는 머리는 `HAIR_COVERS_EARS` 에 등록
4. **카메라 인식은 자동으로 따라옵니다** — 프론트가 선택지 목록을 그대로 서버에 보내고,
   서버가 그걸로 JSON 스키마를 만들기 때문에 목록에 넣으면 후보가 됩니다
   (`AvatarFromPhoto.buildOptions()` → `backend/avatar_vision._build_schema()`)
5. 분류(덮머/가르마/…)를 속성으로 나눌 경우 프롬프트·스키마·매핑 레이어 추가
