# KOWEPS 1~20차 전처리 감사

## 입력

- 가구 Long Form: `koweps_h01_20_long_260331.dta`
- 가구+가구원 Long Form: `koweps_hp01_20_long_260331.dta`
- 공식 결합데이터 1~20차 코드북 ZIP
- 공식 조사표·유저가이드 ZIP

원자료와 개인단위 산출물은 `data/raw`, `data/clean`에만 두며 Git에 포함하지 않는다.

## 재현 명령

```powershell
python preprocess/preprocess_koweps.py
python preprocess/build_koweps_event_panel.py
```

## 변수 사전과 경량 패널

- DTA 변수 2,841개를 공식 코드북 3,204행과 결합했다.
- 9개 삶의 영역 키워드, 사건 후보, 결과 후보를 변수별로 기록했다.
- 원본 1.36GB에서 필요한 298열만 읽어 20.4MB Parquet 패널로 만들었다.
- 최종 패널은 320,142 개인-차수 행, 32,138명, 12,642가구, 1~20차다.

영역별 `2개 차수 이상·200건 이상` 사용 가능 후보 수:

| 영역 | 사용 가능 변수 |
|---|---:|
| 직업 | 45 |
| 교육 | 29 |
| 사업 | 32 |
| 재무 | 62 |
| 건강 | 65 |
| 주거 | 50 |
| 관계 | 47 |
| 생활방식 | 11 |
| 장기 가치 | 28 |

이 숫자는 모델 수가 아니라 변수 후보의 커버리지다. 코드 의미·척도 방향·사건 정의 검증을 통과한 변수만 실제 모델에 쓴다.

## 해석 제한

- 현재 산출물은 사건·결과 커버리지 감사용이며 인과효과나 개인 예측이 아니다.
- 이사는 공식 `지난 1년간 이사경험 여부`를 사용한다.
- 혼인과 가구원 변화는 연속 차수의 상태 변화로 정의한다.
- 취업상태 변화는 개인의 직종 응답 유무로 취업/미취업을 추정했다. 학습 전에 설문
  코드와 다른 고용 변수로 교차검증해야 한다.
- 만족도와 건강 척도의 방향, 비해당·모름 코드, 가중치 선택을 사건별로 추가 검증해야 한다.
- 모델 학습 시 동일 `h_pid`가 학습·검증에 동시에 들어가지 않도록 개인 단위 분할하고,
  과거 차수 학습→최근 차수 검증을 별도로 수행한다.
