# KOWEPS 9영역 시나리오 패널 감사

## 목적과 제한

KOWEPS 1~20차를 Parallel Me의 9개 삶 영역에 연결하기 위한 데이터 적합성 감사다.
현재 산출물은 최초 사건 전후의 기술통계 패널이며, 매칭·가중·시간순 검증 전이다.
따라서 인과효과나 개인별 미래예측으로 해석하면 안 된다.

## 변수 선정 기준

`preprocess/koweps_domain_registry.json`을 단일 명세로 사용한다. 변수는 다음 역할 중
하나가 명확할 때만 원본에서 읽는다.

- 개인·가구 식별 및 조사설계
- 사용자가 비교할 수 있는 선택 사건
- 사건 직전 개인 상태(공변량)
- 사건 1·3·5차 후 결과

기존 298열은 키워드 기반 1차 후보일 뿐이며 최종 필요 변수 목록이 아니다.

## 9개 영역 상태

| 영역 | 현재 상태 | KOWEPS 역할 |
|---|---|---|
| 진로 | 패널 생성 | 직종분류 개정 경계 차수를 제외한 직종 변경 |
| 교육 | 패널 생성 | 교육수준 유지 vs 상승(진학·졸업·정정 혼재 주의) |
| 창업 | 보류 | 자영업소득 발생 25~35세 표본이 작고 proxy임 |
| 재무 | 결과 전용 | 소득·자산·부채 결과. 사용자 선택 사건 미정 |
| 건강 | 결과 전용 | 건강·우울 결과. 건강 악화를 선택으로 취급하지 않음 |
| 주거 | 패널 생성 | 이사, 임차 유지 vs 자가 전환 |
| 관계 | 패널 생성 | 결혼, 가구원 증가·감소. 원인 혼재 주의 |
| 생활방식 | 보류 | 근로시간형태 코드 및 방향 검증 필요 |
| 장기 가치 | 결과 전용 | 전반적 만족도·가치관 결과/개인화 변수 |

## 최초 사건 패널 결과

대상은 기준시점 25~35세다. 동일인의 반복 사건은 최초 1건만 남겼다. 사건·비사건 모두
직전 차수가 연속 관측된 경우만 포함했고, 공변량은 사건 직전 차수 값을 사용했다.

| 시나리오 | 사건군 | 비교군 | 1차 후 사건군 결과 | 3차 후 | 5차 후 |
|---|---:|---:|---:|---:|---:|
| 이사 vs 비이사 | 2,603명 | 3,796명 | 2,257~2,335 | 1,840~1,915 | 1,561~1,620 |
| 미혼 유지 vs 결혼 | 902명 | 2,931명 | 727~732 | 591~595 | 501~508 |

추가 생성된 최초 사건 패널은 직종 변경 1,851명, 교육수준 상승 288명, 자가 전환
1,213명, 가구원 증가 2,380명, 가구원 감소 1,804명이다. 직종 변경은 분류체계 개정
경계인 4·14차 전환을 제외했다.

혼인상태의 모든 변화를 하나로 합치지 않았다. 실측 전환행렬에서 미혼(5)→유배우(1)가
892건으로 확인돼 결혼 시작을 독립 사건으로 정의했다. 유배우→이혼·별거는 별도 사건으로
두고 표본과 공식 값표를 추가 검증한다.

## 코딩 감사에서 확인한 문제

- 만족도는 1~5 척도이며 높을수록 만족도가 높다.
- `9`가 섞인 만족도·건강·우울 값은 유효 점수에서 제외했다.
- 혼인상태·건강상태·근로시간형태는 결합 코드북에 값 설명이 비어 있는 부분이 있어
  공식 조사표 값표를 추가 대조해야 한다.
- 사건 발생 차수의 상태를 공변량으로 쓰면 사후정보 누수이므로 직전 차수 값으로 교정했다.
- 현재 비교군은 대상 연령 동안 해당 사건이 없었던 사람의 최초 eligible 관측이다.
  사건군과 나이·성별·혼인·주거·소득 구성이 다르므로 단순 평균 차이를 효과로 쓰면 안 된다.

## 다음 모델링 단계

1. 사건 차수별 risk-set 비교군 구성 또는 propensity overlap 확인
2. 개인 단위 학습/검증 분리와 과거→최근 차수 시간검증
3. 가중 기술분포 산출 및 표본 이탈 점검
4. 검증을 통과한 결과만 UI의 관측 범위로 연결
5. 점추정 인과효과는 별도 강건성 검증 전까지 노출 금지
