# data/reference — 외부 기준표

## cpi_korea_2020base.csv
소비자물가지수(총지수, 연간, **2020=100**). KLIPS 명목 월임금을 실질임금으로
환산할 때 쓴다. `preprocess/preprocess_klips.py` 가 읽는다.

    실질임금(기준연도 t0) = 명목임금(연도 t) × CPI[t0] / CPI[t]

범위: **1998~2024** (KLIPS 1~27차 전 구간).

### 출처가 두 가지다 — `note` 컬럼으로 구분한다
| 구간 | 출처 | 비고 |
|---|---|---|
| 2015~2024 | KOSIS 공표치 수기 입력 | 기존 값. 손대지 않았다 |
| 1998~2014 | World Bank `FP.CPI.TOTL`(2010=100) 를 2020=100 으로 재기준 | 아래 대조 결과 참조 |

세계은행 계열은 각국 공식 통계를 그대로 싣는다. 겹치는 2015~2024 구간에서
재기준 값과 기존 KOSIS 값을 대조하면 **최대 차이 0.03**(10개 중 7개는 완전 일치)
이라 같은 계열임이 확인된다. 차이는 반올림 자릿수 때문이다.

재현:

    curl "https://api.worldbank.org/v2/country/KOR/indicator/FP.CPI.TOTL?format=json&per_page=100&date=1995:2024"
    # 각 연도 값 ÷ 2020년 값 × 100

⚠️ **검증 필요**: 배포 전에 KOSIS(통계청) 「소비자물가조사 > 소비자물가지수」
원표와 대조해 확인할 것 — 특히 1998~2014 구간은 KOSIS 원표를 우선한다.
연도를 추가하려면 이 파일에 행만 추가하면 되고, 전처리 스크립트는 필요한
연도가 이 표에 없으면 **에러로 중단**한다(추정치를 만들어 쓰지 않는다).
